# Flow · 待办清单

一个轻量、美观、功能丰富的纯前端待办清单网页。零依赖、零构建，打开即用。

## ✨ 功能

- **任务管理**：添加 / 完成 / 编辑（双击或 ✏️）/ 删除，Enter 快速添加
- **任务属性**：优先级（高 / 中 / 低）、截止日期（逾期自动标红）、自定义标签
- **筛选搜索**：全部 / 进行中 / 已完成 筛选，关键词实时搜索（匹配标题和标签）
- **多种排序**：按创建时间、优先级、截止日期、字母排序
- **拖拽排序**：拖动左侧 ⋮⋮ 手柄自由调整顺序
- **进度统计**：完成率进度条 + 鼓励语 + 任务计数
- **深色模式**：一键切换，按 `T` 键快速切换，偏好自动保存
- **数据持久化**：localStorage 自动保存，刷新不丢失
- **数据导出**：一键导出 JSON 备份
- **批量清理**：一键清除已完成任务
- **响应式**：适配手机 / 平板 / 桌面

## 🚀 本地运行

直接双击 `index.html` 即可，或起一个本地服务器：

```bash
python -m http.server 8080
```

## 🌐 部署（GitHub + Vercel）

1. 在 GitHub 新建一个仓库，把这三个文件上传（或 `git push`）
2. 打开 [Vercel](https://vercel.com) → **Add New → Project** → 导入该仓库
3. Framework 选 **Other**，无需任何 Build 配置，直接 **Deploy**
4. 几秒后即可获得 `https://你的项目名.vercel.app` 的在线地址

之后每次 push 到 GitHub，Vercel 会自动重新部署。
